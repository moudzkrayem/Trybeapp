
# Trybe App

The vibrant social event app for local trybes. Discover, create, and connect with people sharing your passions.

## GitHub Repository
This project is linked to: [https://github.com/moudzkrayem/usetrybe](https://github.com/moudzkrayem/usetrybe)

## Features
- **Discovery**: Find local events using the feed or an interactive map.
- **Creation**: Lead your own trybe with AI-assisted descriptions and tags.
- **Engagement**: Swipe to discover new vibes and join communities instantly.
- **Connection**: Private group chats for every event you join.

## Getting Started
To get started, take a look at `src/app/page.tsx`.

### Prerequisites
- Node.js (Latest LTS recommended)
- Firebase Account

### Setup
1. Clone the repository:
   ```bash
   git clone https://github.com/moudzkrayem/usetrybe.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
