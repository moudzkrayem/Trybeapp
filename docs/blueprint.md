# **App Name**: Tribe Hub

## Core Features:

- Event Creation Tool: An intuitive interface for users to create and customize their own events.
- Nearby Event Feed: A browsable feed displaying local events based on user's location or preferences.
- RSVP and Tracking: Allow users to RSVP for events and track participants.
- In-App Messaging: Enable real-time communication between event organizers and attendees.

## Style Guidelines:

- Primary color: Vibrant coral (#FF7F50) to convey energy and community. Based on the colors present in the provided reference image, specifically the image representing Wadi Rum.
- Background color: Dark slate gray (#303030) to provide a modern and engaging backdrop. Influenced by the color scheme present in the reference image provided.
- Accent color: Amber (#FFBF00) used for interactive elements and highlights. This hue comes from the 'PROMOTED TRYBE' label found in the original image.
- Headline font: 'Poppins' sans-serif font for clear, modern headings. Also like the style present in the 'Wadi rum Hike' label in the provided image.
- Body font: 'Inter' sans-serif font for readable, accessible body text.
- Use a set of clean, modern icons to represent various event categories and actions.
- Design a card-based layout to display events in an organized manner.
